# E-Commerce Delivery & Logistics Performance Analysis

Team project to analyze e-commerce delivery performance using Python, PostgreSQL, Excel, and Power BI.

## Objectives
- Analyze delivery time and delays
- Measure on-time delivery performance
- Explore order status and customer reviews
- Build an interactive Power BI dashboard

## Dataset
Olist Brazilian E-Commerce Dataset:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Power BI Dashboard Implementation

### Core Key Performance Indicators (KPIs)
- **Total Orders:** 99,441
- **On-Time Delivery Rate:** ~91.88%
- **Cancellation Rate:** ~0.63%
- **Average Delivery Duration:** 12.56 days
- **Average Delay (Late Orders):** 9.55 days
- **Average Customer Rating:** 4.09 / 5.00 stars (On-time: 4.29 vs. Late: 2.57)

### Dashboard Pages (`Ecommerce_Logistics_Dashboard.pbix`)
1. **Executive Overview:** High-level KPIs, monthly volume trends, and order fulfillment status breakdown.
2. **Regional Performance & Routes:** State-wise delivery duration analysis and seller volume vs. on-time efficiency.
3. **Delay Diagnostics:** Fulfillment breakdown separating warehouse processing time from courier transit time, alongside day-of-week latency heatmaps.
4. **Customer Experience (CX):** Rating decay analysis evaluating review score drops relative to delay days.
